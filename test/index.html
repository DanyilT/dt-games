Tetris: replay test

A bot plays Tetris here through the page's own controls. Each run the game finishes is played again with GameRules.simulate() (js/rules.js, what GameHub's server checks runs with), and must come out as the game said. The game here saves under a name of its own, so your best score and game in progress stay as they were. Keep this tab on screen while it runs.

Press Start (or open this page with ?start).
