Bounce: replay test

A bot plays Bounce here through the page's own keys and its keypad (sometimes two fingers at once), stepping the game itself. Each run the game finishes is played again with GameRules.simulate() (js/rules.js, what GameHub's server checks runs with), and must come out as the game said. The game here saves under a name of its own, so your best scores and game in progress stay as they were.

Press Start (or open this page with ?start).
